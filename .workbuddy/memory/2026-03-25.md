## 站点结构审计

完成了 xiaobo-news-v2 站点的全面代码审计，输出了专业优化方案文档。

**站点基本信息：**
- 技术栈：Astro 6 + React 19 + Tailwind CSS 4 + Supabase + Vercel 静态部署
- 部署方式：GitHub Actions 触发构建，静态输出到 Vercel
- 数据源：Supabase（articles 表，1015+ 篇文章）

**发现的核心问题：**
1. 双语页面不一致：英文版 lang="zh-CN"、广告位混用中文、日期格式仍用 zh-CN、加载按钮中文未翻译
2. /blog 和 /en/blog 是静态假数据占位符，与 Supabase 数据完全脱节
3. 两套风格系统并行：主页内联 CSS 蓝色渐变风 vs 其他页面 Tailwind 白底风
4. output:'static' 与动态数据需求存在架构矛盾
5. data-category 属性语法错误导致分类过滤失效
6. BaseLayout 被闲置，主页自成一体，三套 Header/Footer 并存

**优化方案已输出到 Artifact：** xiaobo-news-audit.md（含10个 Bug 速查表 + 4周执行路线图）

**下一步建议（P0）：**
- 修复 data-category 语法错误
- 修正英文版 lang="en"
- /blog 接入 Supabase 真实数据
- 创建 NewsLayout.astro 统一双语布局
