# 晓波智能资讯站 - 技术架构文档 v1.0

**创建时间**: 2026-03-17  
**版本**: v1.0 (基石版本)  
**架构类型**: JAMstack + Serverless API

---

## 🏗️ 架构概览

```
┌─────────────────────────────────────────────────────────┐
│                    用户浏览器                            │
└───────────────────┬─────────────────────────────────────┘
                    │ HTTP 请求
                    ▼
┌─────────────────────────────────────────────────────────┐
│              Vercel CDN (静态托管)                       │
│  ┌───────────────────────────────────────────────────┐  │
│  │  dist/ (构建时生成的静态 HTML/CSS/JS)              │  │
│  └───────────────────────────────────────────────────┘  │
└───────────────────┬─────────────────────────────────────┘
                    │ JavaScript 运行时请求
                    ▼
┌─────────────────────────────────────────────────────────┐
│           Supabase (云端 PostgreSQL 数据库)              │
│  - articles 表 (文章数据)                                │
└─────────────────────────────────────────────────────────┘
```

---

## 🔄 完整数据流

```
1. RSS 抓取 → SQLite (news.db)
2. 数据同步 → Supabase (PostgreSQL)
3. 构建部署 → Vercel CDN (dist/)
4. 用户访问 → 静态 HTML + JS 动态加载
```

---

## ⚙️ 关键配置

### astro.config.mjs
```javascript
export default defineConfig({
  output: 'static',  // 静态站点
  build: { format: 'directory' }
})
```

### src/lib/supabase.ts
- Supabase 客户端配置
- 文章查询逻辑 (优先有日期的文章)
- NULL 日期处理

### tools/*.py
- rss_aggregator.py - RSS 抓取
- sync_to_supabase.py - 数据同步

---

## 🎯 优化方案

### 1. 自动同步 (数据层)
- GitHub Actions 定时执行
- 每 6 小时自动抓取更新

### 2. ISR 增量更新 (构建层)
- Vercel 自动重新验证
- 每小时重新生成页面

### 3. 客户端刷新 (展示层)
- JavaScript 定时获取最新数据
- 每 5 分钟后台刷新
