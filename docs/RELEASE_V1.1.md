## 📊 技术架构

### 前端
- **框架**: Astro 6.0
- **样式**: Tailwind CSS + 自定义
- **部署**: Vercel CDN
- **模式**: 静态站点 + 客户端动态加载

### 后端
- **数据库**: Supabase PostgreSQL
- **API**: Supabase REST API
- **同步**: GitHub Actions 定时任务

### 自动化
- **RSS 抓取**: 每 6 小时自动执行
- **数据同步**: 自动同步到 Supabase
- **页面更新**: ISR + 客户端刷新
